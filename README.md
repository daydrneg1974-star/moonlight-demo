# Лунный свет — демо приложения

Статическая сборка демо-режима мобильного приложения кофейни «Лунный свет» (заказы без сервера, «виртуальный бариста», демо-банк). Публикуется на GitHub Pages автоматически при каждом пуше в `main`.

Исходный код живёт в приватном репозитории `order-manager-HoReCa`; сюда попадает только результат сборки (`npm run deploy:demo` там).
